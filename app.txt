You are a senior React Native and Expo engineer working on a production-quality fitness startup application called SPOT.

Your task is to build the first UI prototype of the application.

IMPORTANT
Do not build the backend.
Do not add authentication.
Do not add AI integration.
Do not add payments.
Do not add MongoDB or API calls.

The goal of this phase is to build a beautiful, functional, high-quality mobile UI prototype using mock data.

---

# PRODUCT

App name SPOT

Tagline

Train smarter. Progress automatically.

SPOT is an adaptive workout application.

The core idea

The user should open the app and immediately know what to do next.

SPOT remembers previous workouts, tracks progress and eventually recommends what weight and reps the user should perform.

The UX philosophy is

Less thinking.
More training.

The application should feel premium, minimal, athletic and intelligent.

Do NOT make it look like an old-school bodybuilding application.

Avoid

 excessive gradients
 neon gaming UI
 too many colors
 excessive shadows
 cluttered dashboards
 generic fitness stock images

The visual direction should feel like a combination of

 premium Apple fitness UI
 modern health applications
 professional athletic software
 minimal dark SaaS design

# IMPORTANT UX REQUIREMENTS

The application must be optimized for using inside a gym.

Users may have

 sweaty hands
 limited time between sets
 one hand available
 poor internet

Therefore

 buttons should be large
 touch targets should be comfortable
 important actions should be obvious
 the UI should not feel crowded
 the active workout screen should prioritize weight and reps
